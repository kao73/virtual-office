# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/);

## [Unreleased]

### Changed

- Ревизия концепта 2026-08-14 (Р-28…Р-35): объём v1 сокращён, дорожная карта §12
  заменена лестницей мелких шагов (`docs/v1-scope.md`), первой ролью назначен
  Уточнитель вместо Делопроизводителя, реализация шва переведена на Go.

### Removed

- Подпроект 1а «Шов» на Python (`adapters/`) удалён из рабочего дерева и заморожен
  тегом `archive/python-adapter` (Р-29): офис ставится в чужие проекты, статический
  бинарь не требует у клиента ни Python, ни uv, ни venv.
- Спеки и планы подпроектов 1а/1б перенесены в `superseded/` — они описывают
  отменённую разбивку (реестр провайдеров, конформанс-сьют, Делопроизводитель первым).

### Added

- Независимое исследование ландшафта адаптеров трекеров
  (`docs/research/2026-08-14-tracker-adapter-clean-research.md`).
- Карты провайдеров и уроки шва (`docs/providers/`) — эмпирика живых API,
  извлечённая из замороженной первой попытки.

Версия 0.2.0 будет выпущена по завершении шага 3 лестницы (первая роль в бою).
