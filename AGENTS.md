# AGENTS.md

Инструкции для агента, работающего над этим репозиторием. Для Claude Code
то же самое лежит в [`CLAUDE.md`](CLAUDE.md) — он подробнее, читайте его,
если ваш инструмент его подхватывает.

Не путайте два уровня: этот файл — про работу *над* фреймворком. Роли,
которые фреймворк запускает над проектом-клиентом, описаны в `office/roles/`
и настраиваются иначе.

## Читать перед работой

1. [`CLAUDE.md`](CLAUDE.md) — состояние репозитория, замысел, конвенции.
2. [`docs/DESIGN.md`](docs/DESIGN.md) — источник истины по архитектуре.
   Прочитать до любой правки кода.
3. [`docs/guide/development.md`](docs/guide/development.md) — проверки,
   golden-кейсы, релиз, карта репозитория.

## Что не выводится из кода

- **Язык документов — русский.** Идентификаторы, термины и ключи конфигов —
  английские.
- **Архив открывается только по явной просьбе владельца.** Теги `archive/*`
  хранят прежние наработки; не заглядывайте туда по своей инициативе и не
  приносите оттуда готовых решений — замысел продумывается заново.
- **Офис лежит в `office/`** и попадает в бинарник через `go:embed`. Внутри
  уже встроенных каталогов новые файлы подхватываются сами; новая запись
  верхнего уровня в `office/` требует ещё и строки в `office/payload.go`,
  иначе в поставку она не поедет.
