- wiki.go inline(): ссылка внутри жирного текста рвёт пару звёздочек — **[a](b)** даёт **a (b)**, потому что разбор делит строку по границе ссылки раньше bold().
- wiki.go fence(): забор с атрибутами уезжает в {code:go title="x"} — язык берётся всем хвостом строки.
- wiki.go: проза, кончающаяся обратным слэшем прямо перед ссылкой, даст ...\[текст|url] — слэш экранирует уже построенную ссылку. Случай крайне узкий.
- ParseQuestions не знает про заборы блоков кода, а wiki() знает: `## Вопросы` внутри блока уедет сырым и будет принят разбором за начало раздела. Досталось от master.
- Изменение целиком лежит в рабочем дереве: коммита нет ни одного.
