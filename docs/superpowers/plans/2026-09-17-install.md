# install Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the office inside the `runner`/`run-agent` binaries and give a machine without a clone or a Go toolchain a working install path: `install.sh` → `runner init` → `runner version` → `runner tick`, every run signed with the release version.

**Architecture:** A data-only root package `office` (`payload.go`) embeds `roles/`, `skills/`, `hooks/`, `workflow.yaml`, `budgets.yaml`, both samples and `bootstrap/sbx-kits/`; `internal/office` unpacks that FS temp-then-rename into `${OFFICE_HOME}/office/<dir>/` restoring executable bits from shebangs; `internal/runner.ResolveOffice` picks one of four branches (clone by `OFFICE_CONFIG_ROOT`, release version from ldflags, `vcs.revision` from build info, refusal) and returns `runner.Office{Root, Identity, Source}` which replaces every `configRoot string` downstream; `EnsureValidator` builds the checker in clone mode and hands out an embedded one (`//go:build release` + GOOS_GOARCH files) in payload mode; GoReleaser + one tag workflow publish three tar.gz archives, `checksums.txt` and `install.sh`.

**Tech Stack:** Go 1.26 (stdlib only: `embed`, `io/fs`, `testing/fstest`, `runtime/debug`), POSIX `sh`, GoReleaser v2.18.2 via `go run`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-17-install-design.md` (the Design Doc — authority on HOW). High-level decisions D1–D9: `docs/openspec/changes/install/design.md`. Acceptance scenarios: `docs/openspec/changes/install/specs/office-distribution/spec.md` and `specs/office-install/spec.md`. Task boundaries: `docs/openspec/changes/install/tasks.md` — the six groups below are its six sections in order, and every task names the `tasks.md` items it closes.

## How to use this plan

Tasks are ordered; each ends with a green `go build ./... && go vet ./... && go test ./...` and one commit. A task's implementer sees only that task: the **Interfaces** block tells them what earlier tasks produced (exact names) and what later tasks will call. Code blocks are sketches with the load-bearing lines (signatures, error texts, the tricky branch); fill the obvious parts in the repository's style. Comments and user-facing strings in Go and shell are Russian; identifiers English; prose in this plan is English.

## Global Constraints

- **Wire names do not change.** Marker key `config:`, JSON field `config_sha` (passport `run.json`, `ledger.jsonl`), and the Go identifiers `ConfigSHA` on `runner.Run`, `ledger.Entry`, `tracker.Marker`, `pipeline.Office` all stay. Only their doc-comments change to "личность офиса: версия релиза или commit".
- **`OFFICE_CONFIG_ROOT` clone mode is byte-for-byte today's behaviour**: roles from that directory, identity `git rev-parse HEAD` + `-dirty`, checker built by `go build` from that directory, nothing unpacked. The wrappers `bin/runner` and `bin/run-agent` are not edited.
- **The cwd fallback is removed** from `cmd/runner` and `cmd/run-agent`. `cmd/eval-roles` keeps its own `officeRoot()` untouched (it is a clone tool reading `evals/`).
- **`internal/adapters/claude/adapter.go` is read-only** for this change (`copyHooks`, `copyExecutable`, `buildPlugin` read whatever root they are handed). Only `hook_test.go` gets a one-line signature update.
- **The root package imports nothing internal**; `internal/office` imports only stdlib; `internal/runner` imports both. The root package is imported under the alias `payload` everywhere outside itself (`payload "github.com/kao73/virtual-office"`), because `internal/office` is also named `office`.
- **`cmd/validate-result` must not grow.** It imports `internal/runner`; the payload must stay unreachable from its `main` so the linker drops it (verified empirically: an unreferenced `embed.FS` is stripped; a package-level `var x fs.FS = payload.Payload` would keep it). Rule: never initialise a package-level variable from `payload.Payload`/`payload.Validators`; reach them through functions (`payloadOrDefault()`, `validatorsOrDefault()`). Task 3 checks the checker's size (today 3.7 MB; must stay under 5 MB).
- **Executable bits come from the shebang** (D2): on unpack `#!` → `0755`, else `0644`. Files that start with `#!` but are not executable in git (the `skills/comet*/scripts/*.mjs`) become executable after unpack; that is accepted and not tested.
- **`go test ./...` stays hermetic**: no network, no GoReleaser, no real agent, no `sbx`. The shell test and the snapshot check are run by hand (Tasks 12–13) and recorded in `docs/notes/install.md`.
- **Russian in code and CLI, English in this plan.** Every Go file `gofmt`-clean; every commit ends with `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>`.
- **Out of scope (Design Doc §6):** cleanup of old `office/<dir>/`, `doctor`, self-update, Homebrew, darwin/amd64, automatic bake, `bootstrap/*.plist|.service`, `docs/ONBOARDING.md`, the first tag, a `version` subcommand for `run-agent`.

## go:embed pitfalls (read before Task 1 and Task 6)

1. `embed` skips paths whose element begins with `_` or `.` unless the pattern carries the `all:` prefix. `roles/_base/`, `skills/*/.source.yaml`, `bootstrap/sbx-kits/comet-cli/.source*.yaml` and `…/files/home/.comet-pkg/` all need it: `//go:embed all:roles all:skills all:hooks all:bootstrap/sbx-kits`.
2. `embed.FS` stores no file modes. Modes are restored at unpack from the first two bytes (`#!`).
3. Patterns cannot contain `..` or leave the package directory — that is why the package lives at the module root.
4. A pattern that matches nothing is a compile error. `payload/validators/validate-result-<os>-<arch>` patterns therefore only compile after `scripts/build-validators.sh` ran; that is intended (`//go:build release` keeps plain `go build` compiling). The directory `payload/validators/` must exist in git — a tracked `README.md` keeps it present.
5. Per-target files use the Go filename convention `validators_<GOOS>_<GOARCH>.go` (constrained by name) **plus** the `//go:build release` line; `validators_dev.go` carries `//go:build !release` and declares `var Validators embed.FS` without a directive — the zero `embed.FS` is a valid empty file system whose `Open` returns `fs.ErrNotExist`.
6. `//go:embed` may be written on several consecutive lines before one `var`; only blank lines and `//` comments may sit between the directive and the declaration.
7. Empty directories and symlinks cannot be embedded; the payload has neither (checked at plan time).

// walkDisk обходит файлы каталога поставки на диске.
func walkDisk(t *testing.T, dir string, fn func(path string, info fs.FileInfo)) {
	t.Helper()
	err := filepath.WalkDir(dir, func(path string, d fs.DirEntry, err error) error {
		if err != nil || d.IsDir() {
			return err
		}
		info, err := d.Info()
		if err != nil {
			return err
		}
		fn(path, info)
		return nil
	})
	if err != nil {
		t.Fatalf("%s не обойдён: %v", dir, err)
	}
}

package office

// bootstrapPrefix — каталог, который в репозитории оборачивает кит песочницы
// (bootstrap/sbx-kits/…), а в распакованном офисе не нужен: там кит лежит
// как sbx-kits/…, рядом с roles/ и hooks/.
const bootstrapPrefix = "bootstrap/"

// tempPrefix — как называется каталог распаковки, пока она не кончилась.
// Осиротевший после убитого процесса он остаётся лежать: чистить его
// некому — соседний tick мог начать свою распаковку в этот же момент.
const tempPrefix = ".unpack-"

// Unpack раскладывает src в <officeDir>/<name> и отдаёт путь.
//
// Сперва — во временный каталог рядом, потом одним переименованием: читатель
// либо не видит каталога вовсе, либо видит его целиком. Если к моменту
// переименования каталог уже есть (второй раннер успел раньше или офис
// распакован давно), временный удаляется, а существующий остаётся как есть —
// перезаписывать его нельзя: правка руками в нём законна.
//
// Права: embed их не хранит, поэтому файл, начинающийся с «#!», получает 0755,
// остальные — 0644. Свой обход, а не os.CopyFS: тот не умеет ни прав, ни
// переноса bootstrap/ на уровень выше.
func Unpack(src fs.FS, officeDir, name string) (string, error) {
	target := filepath.Join(officeDir, name)
	if err := os.MkdirAll(officeDir, 0o755); err != nil {
		return "", fmt.Errorf("каталог офисов не создан: %w", err)
	}
	// Уникальный суффикс, а не только pid: две горутины одного процесса
	// не должны писать в один временный каталог.
	tmp, err := os.MkdirTemp(officeDir, tempPrefix+name+"-")
	if err != nil {
		return "", fmt.Errorf("временный каталог распаковки не создан: %w", err)
	}
	if err := os.Chmod(tmp, 0o755); err != nil { // MkdirTemp даёт 0700
		_ = os.RemoveAll(tmp)
		return "", err
	}
	if err := copyTree(src, tmp); err != nil {
		_ = os.RemoveAll(tmp)
		return "", fmt.Errorf("офис %s не распакован: %w", name, err)
	}
	switch err := os.Rename(tmp, target); {
	case err == nil:
		return target, nil
	case errors.Is(err, fs.ErrExist):
		// EEXIST и ENOTEMPTY: кто-то успел раньше. syscall.Errno.Is сводит
		// оба к fs.ErrExist.
		_ = os.RemoveAll(tmp)
		return target, nil
	default:
		_ = os.RemoveAll(tmp)
		return "", fmt.Errorf("офис %s не переименован из временного каталога: %w", name, err)
	}
}

// copyTree пишет каждый файл src под dst; каталоги создаются по пути.
func copyTree(src fs.FS, dst string) error {
	return fs.WalkDir(src, ".", func(path string, d fs.DirEntry, err error) error {
		if err != nil || d.IsDir() {
			return err
		}
		data, err := fs.ReadFile(src, path)
		if err != nil {
			return err
		}
		out := filepath.Join(dst, filepath.FromSlash(strings.TrimPrefix(path, bootstrapPrefix)))
		if err := os.MkdirAll(filepath.Dir(out), 0o755); err != nil {
			return err
		}
		mode := fs.FileMode(0o644)
		if bytes.HasPrefix(data, []byte("#!")) {
			mode = 0o755
		}
		if err := os.WriteFile(out, data, mode); err != nil {
			return err
		}
		// umask может срезать биты при создании — как copyExecutable в адаптере,
		// выставляем явно.
		if mode == 0o755 {
			return os.Chmod(out, mode)
		}
		return nil
	})
}

```go
// Hash — sha256 по содержимому src: путь, длина и байты каждого файла в
// порядке обхода (он лексический, значит устойчивый). Нужен грязным сборкам:
// две сборки одного commit могут нести разные роли, и каталог распаковки
// у них должен различаться (internal/runner.ResolveOffice).
func Hash(src fs.FS) (string, error) {
	h := sha256.New()
	err := fs.WalkDir(src, ".", func(path string, d fs.DirEntry, err error) error {
		if err != nil || d.IsDir() {
			return err
		}
		data, err := fs.ReadFile(src, path)
		if err != nil {
			return err
		}
		// Длина между путём и байтами — граница: без неё «a»+«bc» и «ab»+«c»
		// дали бы один хеш.
		fmt.Fprintf(h, "%s\x00%d\x00", path, len(data))
		h.Write(data)
		return nil
	})
	if err != nil {
		return "", fmt.Errorf("поставка не прочитана: %w", err)
	}
	return hex.EncodeToString(h.Sum(nil)), nil
}

// могут нести разные роли, а распакованная версия не переписывается (D3).
func payloadIdentity() (identity, dir string, err error) {
	if payload.Version != "" {
		return payload.Version, payload.Version, nil
	}
	info, ok := readBuildInfo()
	if !ok {
		return "", "", errNoIdentity
	}
	var rev string
	modified := false
	for _, s := range info.Settings {
		switch s.Key {
		case "vcs.revision":
			rev = s.Value
		case "vcs.modified":
			modified = s.Value == "true"
		}
	}
	if rev == "" {
		return "", "", errNoIdentity
	}
	short := rev
	if len(short) > 12 {
		short = short[:12]
	}
	if !modified {
		return rev, short, nil
	}
	hash, err := office.Hash(payloadOrDefault())
	if err != nil {
		return "", "", err
	}
	return rev + "-dirty", short + "-dirty-" + hash[:8], nil
}

// commitHash — 40-hex commit, возможно с -dirty: единственное, что маркер
// сокращает. Версия релиза (v0.7.0) и любая другая личность пишутся целиком.
var commitHash = regexp.MustCompile(`^[0-9a-f]{40}(-dirty)?$`)

func shortenSHA(identity string) string {

		return shorten(strings.TrimSuffix(identity, suffix)) + suffix
	}
	return shorten(identity)

#!/bin/sh
# Установка офиса на машину без клона и без Go: кладёт runner и run-agent
# из релиза в ${OFFICE_HOME:-$HOME/.office}/bin.
#
#   sh install.sh                              # последний релиз
#   sh install.sh v0.7.0                       # конкретный тег (или OFFICE_VERSION=v0.7.0)
#   OFFICE_INSTALL_FROM=dist sh install.sh     # из каталога артефактов, без сети
#
# Нужны: sh, curl или wget, tar, sha256sum или shasum. Контрольная сумма
# проверяется до распаковки; меняются только два бинарника — рабочие файлы
# и распакованные версии офиса в ${OFFICE_HOME} остаются как были.
set -eu

repo="kao73/virtual-office"
version="${1:-${OFFICE_VERSION:-latest}}"
home="${OFFICE_HOME:-$HOME/.office}"
bin="$home/bin"
supported="darwin/arm64 linux/amd64 linux/arm64"

die() { echo "install.sh: $*" >&2; exit 1; }

# 1. Платформа — до всего остального: чужой ничего не качать.
case "$(uname -s)" in Darwin) os=darwin ;; Linux) os=linux ;; *) os="$(uname -s | tr '[:upper:]' '[:lower:]')" ;; esac
case "$(uname -m)" in arm64|aarch64) arch=arm64 ;; x86_64|amd64) arch=amd64 ;; *) arch="$(uname -m)" ;; esac
case " $supported " in
  *" $os/$arch "*) ;;
  *) die "платформа $os/$arch не поддерживается; есть сборки для: $supported" ;;
esac

archive="virtual-office_${os}_${arch}.tar.gz"
sums="checksums.txt"
tmp="$(mktemp -d)"
trap 'rm -rf "$tmp"' EXIT

# 2. Источник: каталог артефактов или GitHub Releases.
fetch() {  # fetch <файл> — кладёт его в $tmp
  if [ -n "${OFFICE_INSTALL_FROM:-}" ]; then
    cp "$OFFICE_INSTALL_FROM/$1" "$tmp/$1" 2>/dev/null || die "$1 не найден в $OFFICE_INSTALL_FROM"
    return
  fi
  if [ "$version" = latest ]; then url="https://github.com/$repo/releases/latest/download/$1"
  else url="https://github.com/$repo/releases/download/$version/$1"; fi
  if command -v curl >/dev/null 2>&1; then curl -fsSL -o "$tmp/$1" "$url" || die "$1 не скачан: $url"
  elif command -v wget >/dev/null 2>&1; then wget -qO "$tmp/$1" "$url" || die "$1 не скачан: $url"
  else die "нужен curl или wget"; fi
}
fetch "$sums"
fetch "$archive"

# 3. Контрольная сумма — до распаковки.
if command -v sha256sum >/dev/null 2>&1; then actual="$(sha256sum "$tmp/$archive" | cut -d' ' -f1)"
elif command -v shasum >/dev/null 2>&1; then actual="$(shasum -a 256 "$tmp/$archive" | cut -d' ' -f1)"
else die "нужен sha256sum или shasum для проверки $archive"; fi
expected="$(awk -v f="$archive" '$2 == f { print $1 }' "$tmp/$sums")"
[ -n "$expected" ] || die "$archive не значится в $sums"
[ "$actual" = "$expected" ] || die "контрольная сумма $archive не совпала: ожидалась $expected, получена $actual; ничего не установлено"

# 4. Распаковка.
mkdir -p "$tmp/x"
tar -xzf "$tmp/$archive" -C "$tmp/x" || die "$archive не распакован"
for name in runner run-agent; do [ -f "$tmp/x/$name" ] || die "в $archive нет $name"; done

# 5. Установка: временное имя и mv — атомарно внутри каталога, и работающий
# бинарник заменять так безопасно.
mkdir -p "$bin"
for name in runner run-agent; do
  cp "$tmp/x/$name" "$bin/.$name.tmp"
  chmod 0755 "$bin/.$name.tmp"
  mv -f "$bin/.$name.tmp" "$bin/$name"
done

# 6. Отчёт: что установлено (и что бинарник запускается), PATH, следующий шаг.
echo "установлено в $bin:"
"$bin/runner" version
case ":$PATH:" in
  *":$bin:"*) echo "$bin уже в PATH" ;;
  *) echo "$bin не в PATH — добавьте в профиль оболочки:"; echo "  export PATH=\"$bin:\$PATH\"" ;;
esac
echo "дальше: runner init"
```
