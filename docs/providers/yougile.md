# YouGile — карта провайдера

**Отложен** (Р-30): в v1 трекер один — Jira. Знание сохранено, потому что владелец уже
переезжал YouGile → Jira (Р-04) и обратный или третий переезд не исключён.

Источник: смоук первой попытки против полигона в YouGile.
Общие уроки шва — в [`README.md`](README.md).

## Инстанс и транспорт

| | |
|---|---|
| API | REST v2 — `https://yougile.com/api-v2` |
| Аутентификация | Bearer-токен |
| Переменная окружения | `YOUGILE_API_KEY` |

## Модель отличается от Jira в основаниях

| | Jira | YouGile |
|---|---|---|
| Состояние | статус воркфлоу | **колонка** (`columnId`) |
| Фенс | метка | **доска** (board id) |
| Комментарии | сущность на issue | **чат задачи** |
| Вложения | сущность на issue | **нет** — файл грузится отдельно, ссылка постится комментом |
| Связи между карточками | есть | **нет** |
| Ключ | человекочитаемый (`CRM3-13`) | UUID, человекочитаемого ключа нет |

Это и есть иллюстрация к тезису из исследования: универсальная **модель данных**
между такими трекерами невозможна, универсальные **глаголы** — вполне.

## Операции

```
GET  task-list?columnId={id}&limit=1000     список карточек стадии
GET  tasks/{id}                             карточка
PUT  tasks/{id}  {"columnId": ...}          перемещение = смена колонки
POST tasks       {title, columnId, description}   создание
```

## Фенс — через доску, а доска добывается из колонки

У задачи есть только `columnId`. Доска определяется отдельным запросом:

```
GET columns/{id}  →  boardId
```

Это надо кэшировать: иначе при обходе стадии запрос уходит на каждую карточку.

## Комментарии — это чат задачи

```
GET  chats/{task_id}/messages     →  content[], поле text
POST chats/{task_id}/messages     →  {"text": ...}
```

`timestamp` приходит **в миллисекундах**.

## Вложения — двухшаговые, и в ответе две разные ссылки

```
POST upload-file   multipart  →  ответ содержит url и fullUrl
```

**Грабля:** поле `url` в ответе — **относительный путь** вида `/user-data/...`,
он не начинается с `http`. Нужен **`fullUrl`**.

Дальше ссылка публикуется обычным комментарием — отдельной сущности вложения нет.

Здесь же был найден баг с ретраем, вынесенный в общие уроки: тело файла надо читать
в память **до** первой попытки, иначе повтор отправляет пустой файл.

## Отсутствующая способность

`link` не поддерживается — связей между задачами в API нет. Провайдер обязан честно
объявлять это в capabilities, а не имитировать связь комментарием.
