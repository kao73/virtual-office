# Политика безопасности

## Область

Этот репозиторий — сам framework (`virtual-office`), а не проект-клиент,
который framework разрабатывает через трекер. Уязвимости в коде,
сгенерированном или изменённом ролями (`analyst`/`implementer`/`reviewer`)
в репозитории проекта-клиента — вне области этой политики; сообщайте о них
в тот репозиторий.

## Поддерживаемые версии

Релизов до первого тега ещё не было — поддерживается только актуальный
`master`. После первого стабильного тега список версий появится здесь.

## Как сообщить об уязвимости

Не создавайте публичный issue. Используйте приватный отчёт через GitHub:
Security → Report a vulnerability (private vulnerability reporting включено
для этого репозитория).

Ответ — по мере возможности, формального SLA пока нет: сопровождающий один.
