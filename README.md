# Virtual Office

Виртуальный IT-офис — команда AI-агентов (Аналитик, Разработчик, AI-QA,
Делопроизводитель), ведущая разработку реального проекта по конвейеру
«идея → дизайн → код → приёмка → мерж» с фиксированными гейтами контроля человека.

Упаковка — плагин Claude Code: офис разрабатывается здесь как самостоятельный
продукт-шаблон и подключается к проектам-клиентам установкой плагина + профилем
проекта (`.office/profile.yaml` в репозитории клиента).

## Ключевые принципы

- **«Доска — и есть офис»**: трекер клиента — источник истины и средство общения
  stateless-ролей; центрального оркестратора нет.
- **Фиксированные гейты человека**: дизайн (включая выбор UI-варианта) и мерж
  структурно принадлежат владельцу.
- **Автор ≠ приёмщик**: AI-QA не правит код — только принимает или возвращает.
- **Абстракции по швам**: адаптер трекера, профиль проекта-клиента, профили
  способностей раннеров — офис не знает клиента «зашитым».
